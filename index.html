02 · الإمكانيات

كل ما يحتاجه المشروع، في مكان واحد

محرّك ذكاء اصطناعي

يفهم طلباتك، يعدّل التطبيق حسب الأوامر، يضيف ميزات جديدة، ويصلح الأخطاء البرمجية تلقائيًا.

مولّد واجهات UI

تصميم حديث بألوان متناسقة، قوائم، أزرار، صفحات تسجيل دخول، ولوحات تحكم جاهزة.

إدارة ملفات المشروع

ينشئ HTML وCSS وJavaScript، وFlutter/Dart لتطبيقات أندرويد، وقواعد البيانات اللازمة — مع إمكانية التعديل وحفظ النسخ.

معاينة وتجربة حية

قبل التصدير، شاهد شكل التطبيق وجرّب وظائفه، واطلب تعديلات فورية من الذكاء الاصطناعي.

تصدير متعدد الصيغ

احصل على ملفات المشروع كاملة، أو نسخة Web، أو نسخة PWA، ولاحقًا APK لأجهزة أندرويد.

05 · الأسئلة الشائعة

أسئلة قد تدور في بالك

هل يفهم المحرك أي جملة عربية حرة؟

الإصدار الحالي يحلل الفكرة عبر كلمات مفتاحية شائعة (عملاء، مخزون، فواتير…) ويبني الهيكل المناسب تلقائيًا. كلما كان الوصف أوضح، كانت النتيجة أدق.

هل أحتاج خبرة برمجية لاستخدامه؟

لا. تكتب فكرتك بلغة طبيعية، والمشروع يُبنى جاهزًا. لتعديلات أعمق، الملفات الناتجة كود ويب قياسي يفهمه أي مبرمج لاحقًا.

كيف أحصل على تطبيق أندرويد فعلي؟

يُولَّد مشروع Flutter/Dart كامل مع ملف بناء تلقائي عبر GitHub Actions، يبني لك APK حقيقيًا قابلاً للتثبيت مجانًا خلال دقائق.

هل بياناتي أو رمز GitHub الخاص بي يمر عبر خادم؟

لا. الأداة بالكامل ملفات ثابتة تعمل من متصفحك، والاتصال بـ GitHub يتم مباشرة من جهازك إلى واجهة GitHub دون أي وسيط.
